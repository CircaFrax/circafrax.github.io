CircaFrax OS - 70% Terminé

Version 1.0 • Base figée 32 paquets Arch pur Live • Sans installateur

CircaFrax OS est un système Arch minimal, développé à la main, figé pour durer. Il démarre en quelques secondes en live, sans compte, sans traceur. Objectif : ressusciter vieux PC, travailler offline, maîtriser chaque paquet.

  • 32 paquets audités — pas de bloat
  • Boot live USB, persistance optionnelle
  • Réseau coupé par défaut, outils offline
  • ISO reproductible, doc incluse

Mwangaza OS - Base figée

Kiosque • Offline Savoir utile Dérivé CircaFrax OS PC modestes

Dérivé de CircaFrax OS, Mwangaza est un OS kiosque de savoir. Conçu pour les ordinateurs les moins puissants, destinés aux zones sans internet. Encyclopédie, cours, outils libres — tout offline, maintenu et libre.

  • Kiosque verrouillé, anti-casse
  • Contenu éducatif offline préinstallé
  • Tourne sur 1 Go RAM, vieux CPU
  • Même base figée, même sobriété
